# tls/

Generated by `../gen-cert.sh`, not committed (see `../.gitignore` - this file is the one deliberate exception).

| File       | Purpose                                                              |
|------------|------------------------------------------------------------------------|
| `ca.crt`   | Local test CA certificate. Distribute this (never `ca.key`) to remote `crdsectl` agents' trust stores (`crdsectl.sh trust <ca-cert-path>`) so they can validate this hub's leaf cert. |
| `ca.key`   | Local test CA private key. Never leaves this directory, never committed. |
| `ca.srl`   | OpenSSL CA serial number state, regenerated alongside the leaf cert.  |
| `tls.crt`  | This hub's leaf certificate (nginx), signed by `ca.crt`.               |
| `tls.key`  | This hub's leaf private key.                                          |

`ca.key`/`ca.crt` are only generated once and reused on later runs; `tls.key`/`tls.crt` are regenerated fresh every
run. Not for production - see `../gen-cert.sh` and the "Files" section of `../README.md` for the full picture
(validity periods, why the CA is reused but the leaf isn't, what to use instead in production).
